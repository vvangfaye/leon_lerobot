# 中文语音与操作确认

继续使用 `record_platform.py`。重启程序并刷新页面，左上方“中文语音提示”提供开关、音量、试听，以及晓晓女声 / 云希男声。默认开启晓晓女声，音量 85%。偏好保存在当前浏览器中，声音从打开页面的电脑播放。

使用微软中文神经语音 `zh-CN-XiaoxiaoNeural`、`zh-CN-YunxiNeural`，由 edge-tts 预生成。82 段 MP3 随代码保存在 `nero_platform/static/voice/`，采集运行时无需安装 TTS 依赖或连接语音服务，也不会把任务描述或数据集内容发送到外部。音色列表见 [微软文档](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts)，生成工具见 [edge-tts](https://github.com/rany2/edge-tts)。

## 这次先验证

1. 点击“试听”，确认浏览器所在电脑能发声，再切换两种音色、调整音量。
2. 点击“返回默认位置”：弹窗按单对/双对模式显示两条/四条臂的名称与 CAN 通道，并播报检查所有运动路径的环境提醒。语音结束前不能确认；播完也不会自动执行。先点“取消”，验证没有动作，再按需重新打开并确认。回位期间播报“主从臂正在返回默认位置，注意周边环境”，完成后提示保持使能。
3. “结束采集”只保存和收尾，不失能。结束后单独点击“机械臂失能”：先提醒托住机械臂或增加缓冲垫，并放稳夹持物。准备好并点击“已托稳，确认失能”后才执行。单臂“回位后失能”、失败后的“仅重试失能”也有对应提醒与确认。
4. 准备一集，提醒播到一半时即可点击“② 确认并继续（跳过语音）”：准备语音立即停止，随后准备设备、对齐从臂并录制，无需等播完。后续对齐、开始、保存及已保存提示仍正常播报；自动到时也应播报保存结果。重复刷新状态不会反复播报同一阶段，初次打开页面不播报历史保存结果。
5. 连接、读取状态、微动、保存配置、相机/角色选择、只读失能复核和重试数据收尾均有提示。成功与失败依照接口或后续实际状态反馈播报，不把“请求已发送”当作完成。

“结束一集”立即请求停止，不等待语音播完。播报由浏览器执行，不进入采样线程。更新的状态提示会取消旧提示，避免排队播放过时状态；确认弹窗的提醒不会被后台普通播报打断。

保存提示统一由状态变化触发：“停止中 → 保存中”只播一次，即使上一句已经播完也不重复。正在播放的同一句普通提示不会从头重播；弹窗的“重新播放”仍可主动重播。状态请求交错返回时忽略过期响应，避免重复播报回位或误报完成。隐藏标签页会立即停音，只更新文字和状态，切回来不补播旧提示。

同一浏览器、同一工作台地址打开多个可见页面时，仅最近打开或操作的页面发声；切换窗口、切回标签页或点击另一页面会停止原页面声音。各页面仍持续观察状态，不会切回来又补播历史“回位完成”。禁用浏览器存储时退回焦点判断。不同浏览器、不同地址（例如 localhost 与 IP）或不同电脑不共享此机制，请仅保留一个窗口开启语音。更新后需要刷新所有已打开的工作台页面，让它们使用新版播放器。

浏览器可能拦截音频，也可能没有连接扬声器。点击试听检查；音频加载失败、被拦截、静音或超时后，弹窗会明确显示“语音未播放或已关闭”，仍须阅读完整文字并手动确认，不会自动执行。语音不能确认人已托稳机械臂。

## 修改提示文案

文案与音色定义在 `nero_platform/static/voice/prompts.json`。只在开发时使用独立环境安装 `edge-tts==7.2.8`，运行 `generate_platform_voice.py --force` 重新生成 MP3；也可用 `--cue home_warning --force` 只更新指定提示音。生成阶段需要联网，只提交这些固定提示文案。文案变化时同步增加 manifest 的 `version`，让浏览器取得新版音频。

音频文件使用临时文件生成后再替换，生成失败不会覆盖已有文件。仅修改文案但没有重新生成音频，会造成语音与文字不一致，应一起更新。

软件检查：`test_voice.py` 检查本地文件与 Flask 路由，`test_voice_ui.cjs` 用模拟音频和 HTTP 验证确认前零动作、取消、播放失败、重复点击、状态播报和停止不等待语音；`test_record_ui.cjs` 保留原有页面门禁检查。这些测试不连接机械臂或相机；实际听感和现场流程仍需上述真机验收。
